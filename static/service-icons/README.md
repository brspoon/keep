## Plex wordmark

As of 2026-10-02, `plex.svg` is the unmodified current full-color wordmark
served by [Plex’s official brand guide](https://brand.plex.tv/document/439975#/visual/logo).
It replaces the older Dashboard Icons application icon; that collection’s
license still accompanies the four other marks above.

Original SVG:
https://cdn-assets-cloud.frontify.com/s3/frontify-cloud-files-us/eyJwYXRoIjoiZnJvbnRpZnlcL2ZpbGVcLzFKaXRVVWhFUXZmWXM3NmRYdmk4LnN2ZyJ9:frontify:jMivyR8KlfdJysQZYJAnjyNEiBp69webHH1dg4yh_kQ

The wordmark retains its original colors, paths and 970 × 451 view box.
Connections renders it at 28 pixels wide on a plain dark field in both themes,
inside the same 44-pixel frame as the other service marks. The chevron occupies
about 5.3 pixels at that scale; the frame provides 7 pixels of clear space on
each side and more vertically, exceeding the guide’s minimum chevron-width
margin. No filter, recoloring, cropping, stretching or rotation is applied.
Keep’s own branding remains larger and separate.
