Leaving & watching

Why titles appear, when they may leave, and how watching affects them.

How does Leaving work?

Keep checks titles daily. A title may qualify under its library’s rules, then appear in Leaving. It is not removed from Plex just because it qualifies. Once it appears in Leaving, its day badge shows when removal could happen. An active Keep protects it.

What do the day badges mean?

On Leaving, the number shows days before possible removal from Plex. On Kept, it shows days until the Keep expires. ∞ means the Keep does not expire.

How much do I need to watch?

When available, each library above shows the percentage you need to watch. A shorter play does not update the last watched date Keep uses for Leaving.

What happens after I watch something in Leaving?

After a movie or episode is considered watched, Keep checks its Leaving status during the next daily update. If it no longer meets any Leaving rule, it disappears from Leaving but stays in Plex. If another rule still applies, it stays in Leaving. It may return later after going unwatched long enough.

What does a Keep do?

It protects a title from scheduled removal. A temporary Keep lasts 30 days. Use Manage Keep on a title to see when you can extend it.

When will Keep remind me about titles that are leaving?

Keep emails you when titles enter Leaving and reminds you when they have seven days or less remaining. If an update was missed, the reminder can arrive later. Titles you keep are excluded, and each reminder is sent once per Leaving entry.

Can I choose which emails arrive?

Yes. Turn Keep emails on or off and choose which Leaving lists you want updates about. Your account needs an email address to receive them.

API access

Using Keep’s API and managing API keys.

What can Keep’s API do?

It lets an authorized client read selected Leaving and Kept collections and manage Keep protection. It does not provide media files or delete titles from your media library. Removing a Keep removes protection only.

{% if owner %}Go to API reference ↗{% endif %}
Are API keys the same as connected services?

No. An API key lets a client access Keep’s API as your Keep account. {% if owner %}Plex sign-in and connections such as Maintainerr and Seerr let Keep communicate with those services.{% else %}Connected services let Keep communicate with those services.{% endif %} Changing a service connection does not create an API key.

{% if owner %}Go to Connections ↗{% endif %}
What can an API key access?

A key’s scopes limit which API operations it can request. Your current Keep account permissions still apply, so a key cannot grant its owner extra access.

How do I create or replace an API key?

Only the Keep owner can manage API keys. Create a named key with only the scopes it needs. Keep shows the secret once when you create or rotate a key; copy it to a protected credential store. Rotation replaces the old secret and keeps the key’s existing expiry.

{% if owner %}Manage API keys ↗{% endif %}
When does an API key expire?

New keys expire after 90 days by default. The owner can choose 30, 90 or 365 days, or Never expires. Revoke a key you no longer need.

What happens when I revoke or remove a key?

Revoking a key stops it from authorizing new requests. Remove is available for a revoked key: it removes the credential from the key list and clears its retry and rate-limit records while keeping the audit history.

What does each connection do?
  • Plex provides Plex sign-in, media identity, and access to your selected server.
  • Maintainerr provides Leaving and Kept lists, their rules, and Keep protection.
  • Radarr provides movies and movie libraries for Manage Library.
  • Sonarr provides shows and seasons for Manage Library.
  • Seerr provides request history and helps Keep identify who requested a title. It also helps limit deletion access for users without broader permission.
  • Tautulli provides watches that count, watched percentages, and Leaving forecasts.
  • Email delivery sends invitations, password resets, and Leaving email summaries when enabled.
Go to Connections ↗
Do I need every connection?

Plex and Maintainerr are needed for Keep’s core browsing and protection. The others enable the features above. Manage Library needs Radarr for movies or Sonarr for shows; request history and requester-based deletion access also need Seerr.

What is the difference between Save and Test?

Save stores settings for future use. Test checks the saved settings and records the result. A passed test shows what worked when you ran it; it is not continuous monitoring. Connection tests do not change your media.

Why is information missing when a connection passed its test?

Some features need more than one service or a matching title in a selected Plex library. For example, a Leaving estimate needs the current rules, watched history, and a verified Plex match. Check the other relevant connections and the title’s Plex match.

What does choosing Maintainerr collections do?

Only selected collections appear on Keep’s Leaving and Kept pages. Changing the selection does not erase existing Keeps or email subscriptions.

Why link Seerr accounts?

Keep matches Plex users to Seerr accounts automatically when it can verify their Plex ID. Choose a Seerr account for each local Keep user so their request history can be identified. Linking an account does not grant deletion permission by itself.
